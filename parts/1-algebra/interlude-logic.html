Part I — Algebra · Interlude

On Logic and Mathematical Expressions

A pause between the algebra and the geometry, to look at the language itself. Most mathematical mistakes are not arithmetic slips; they are misreadings of a sentence.

By the end of this interlude you can distinguish a statement from its converse and its contrapositive, disprove a claim with a single counterexample, negate a "for all" or "there exists" statement correctly, use the basic vocabulary of sets, and choose notation that keeps an argument readable.
Before you start

You should have met the even and odd proofs of Chapter 1 and solved a system or two (Chapter 2). This interlude looks back at the language those arguments were already written in — nothing here is new mathematics.

On reading mathematics

A page of mathematics is not read at the speed of a page of prose. It is compressed: a single line may take ten minutes to unpack, and that is normal, not a sign of weakness.

A working method
  1. Read with a pencil. When a computation is shown, do it yourself before reading the next line.
  2. Test every definition on examples. Given a definition, immediately produce two things that satisfy it and one that does not.
  3. Attempt before reading. Try to prove a stated result yourself first; even a failed attempt tells you what the difficulty is, so the proof lands somewhere.
  4. Ask what each hypothesis is doing. If a theorem says "let $a \neq 0$", find the step that would collapse without it.
  5. Do not move on from a sentence you cannot justify. Debt compounds quickly in mathematics.

Implication, converse, contrapositive

Most mathematical statements have the form if $P$ then $Q$, written $P \Rightarrow Q$. $P$ is the hypothesis, $Q$ the conclusion. The statement promises one thing only: that you never have $P$ true while $Q$ is false.

That single arrow spawns two relatives, and telling them apart is the most valuable habit in this interlude.

Three statements built from the same pieces
NameFormRelation to $P \Rightarrow Q$
Statement$P \Rightarrow Q$—
Converse$Q \Rightarrow P$Different statement. May be true or false, independently.
Contrapositive$\text{not }Q \Rightarrow \text{not }P$ Equivalent. Always has the same truth value.

An example makes the difference vivid. Let $P$ be "$n$ is divisible by $4$" and $Q$ be "$n$ is even".

  • $P \Rightarrow Q$: if $n$ is divisible by $4$ then $n$ is even. True.
  • Converse $Q \Rightarrow P$: if $n$ is even then $n$ is divisible by $4$. False — take $n = 6$.
  • Contrapositive: if $n$ is not even then $n$ is not divisible by $4$. True, as it must be.

We have already used the equivalence with the contrapositive twice for real work: in Chapter 1, proving "$n^2$ even $\Rightarrow$ $n$ even" by proving "$n$ odd $\Rightarrow$ $n^2$ odd" instead.

Watch out — the vacuous case

When $P$ is false, $P \Rightarrow Q$ counts as true, whatever $Q$ says. "If $1 = 2$ then I am the Pope" is a true implication. This looks like a trick, but it is forced: the implication promises only that $P$ true with $Q$ false never happens, and if $P$ never happens, the promise is never broken.

When both $P \Rightarrow Q$ and $Q \Rightarrow P$ hold, write $P \iff Q$ and say $P$ if and only if $Q$. Proving an "if and only if" is always two jobs, and it is worth labelling them: ($\Rightarrow$) and ($\Leftarrow$).

For all, there exists, and counterexamples

Two phrases carry most of the weight in mathematical statements:

  • For all $x$, $P(x)$ — written $\forall x$. A universal claim.
  • There exists $x$ such that $P(x)$ — written $\exists x$. An existence claim.

The asymmetry between proving and disproving them is the practical point:

Proving versus disproving
StatementTo prove itTo disprove it
For all $x$, $P(x)$ An argument covering every $x$ — examples are never enough. One counterexample.
There exists $x$ with $P(x)$ One example. An argument covering every $x$.

So the negation of "for all $x$, $P(x)$" is "there exists an $x$ with $P(x)$ false" — and not "for all $x$, $P(x)$ is false". The opposite of "every prime is odd" is not "every prime is even"; it is "some prime is not odd", and $2$ settles it.

Example 1. Killing a plausible rule

Is it true that $\sqrt{a + b} = \sqrt a + \sqrt b$ for all $a, b \ge 0$?

  1. This is a "for all" claim, so one counterexample destroys it.
  2. Take $a = b = 9$. Left side: $\sqrt{18} \approx 4.243$. Right side: $3 + 3 = 6$.
  3. They differ, so the rule is false. $\blacksquare$

Notice that $a = 0$ would not have refuted it — the rule happens to hold there. A counterexample must be a genuine failure, so hunt where cancellation or degeneracy is absent.

Order of quantifiers matters

"For every $x$ there exists $y$ with $y > x$" is true of the real numbers. Swap the order — "there exists $y$ such that for every $x$, $y > x$" — and it claims a number bigger than every number, which is false. Same words, different sentence.

Sets and elements

A set is a collection of objects, its elements. Write $x \in S$ for "$x$ is an element of $S$", and $x \notin S$ for the denial. A set is determined entirely by which objects belong to it — order and repetition are not part of the idea.

Sets are described either by listing, or by a property:

$$\{1, 2, 3, 4\}, \qquad \{\,x \in \mathbb{Z} : x \text{ is even}\,\}.$$

Read the second as "the set of integers $x$ such that $x$ is even". Some sets get permanent names: $\mathbb{Z}$ the integers, $\mathbb{Q}$ the rationals, $\mathbb{R}$ the reals, and $\varnothing$ the empty set, which has no elements at all.

Vocabulary
  • Subset: $A \subseteq B$ means every element of $A$ is an element of $B$. Note this is a "for all" statement — which is why $\varnothing \subseteq B$ always holds, vacuously.
  • Union: $A \cup B = \{x : x \in A \text{ or } x \in B\}$. In mathematics "or" always includes "both".
  • Intersection: $A \cap B = \{x : x \in A \text{ and } x \in B\}$.
  • Difference: $A \setminus B = \{x : x \in A \text{ and } x \notin B\}$.
  • Equality: $A = B$ means $A \subseteq B$ and $B \subseteq A$ — and that is how set equalities get proved, in two halves.

Set language is not decoration: it is how solution sets are described. "Solve $x^2 = 4$" produces the set $\{-2, 2\}$; the solution set of $x^2 = -1$ over the reals is $\varnothing$; and the trichotomy of Chapter 2 was a statement about the size of a solution set — one element, none, or infinitely many.

Notation as a tool

Notation exists to make thinking cheaper. A few habits pay for themselves immediately:

  • Name a thing once, then use the name. If "the number of adult tickets" appears three times in a problem, it should be $a$ from the first line.
  • Use different letters for different objects. In Chapter 1 we wrote $m = 2j$ and $n = 2k$ precisely because reusing $k$ would have silently assumed $m = n$.
  • Say what your letters denote, with units. "Let $t$ be the time in seconds" prevents an entire class of errors.
  • Let the notation carry meaning. $\Delta$ for the discriminant, $|x - a|$ for a distance: good notation reminds you what the object is for.
  • Keep the equals sign honest. $=$ asserts that two things are the same number. A chain of steps in a derivation is a chain of equalities, each of which must actually be true — not a record of the order in which you wrote things down.
Watch out

$\Rightarrow$ and $=$ are not interchangeable. $=$ joins two numbers; $\Rightarrow$ joins two statements. "$x + 1 = 4 \Rightarrow x = 3$" is correct; "$x + 1 = 4 = x = 3$" is meaningless.

Practice

What is the converse of "if $n$ is divisible by $6$ then $n$ is even"?

  • If $n$ is not divisible by $6$ then $n$ is not even.
  • If $n$ is even then $n$ is divisible by $6$.
  • If $n$ is not even then $n$ is not divisible by $6$.
  • $n$ is even and divisible by $6$.

Answer: if $n$ is even then $n$ is divisible by $6$

The converse swaps hypothesis and conclusion. The third option is the contrapositive, which is equivalent to the original and therefore true; the converse here is false ($n = 4$).

What is the contrapositive of "if $x > 2$ then $x^2 > 4$"?

  • If $x^2 > 4$ then $x > 2$.
  • If $x \le 2$ then $x^2 \le 4$.
  • If $x^2 \le 4$ then $x \le 2$.
  • If $x > 2$ then $x^2 \le 4$.

Answer: if $x^2 \le 4$ then $x \le 2$

Negate both parts and reverse the direction. The second option negates without reversing — that is the inverse, which is equivalent to the converse, not to the original. Here the converse is false: $x = -3$ has $x^2 = 9 > 4$ but $x < 2$.

Give a counterexample to "every prime number is odd": state the number.

Answer: $2$

$2$ is prime (its only positive divisors are $1$ and itself) and even. One counterexample is enough to refute a "for all" statement permanently — and $2$ is the only one here, which is why it is called the odd prime out.

What is the negation of "every student passed the exam"?

  • At least one student did not pass.
  • Every student failed.
  • No student passed.
  • Most students failed.

Answer: at least one student did not pass

The negation of $\forall x\, P(x)$ is $\exists x\, \text{not } P(x)$. "Every student failed" is a far stronger claim — it could be false while the original is still false. Denying a universal statement requires only one exception.

Let $A = \{1,2,3,4\}$ and $B = \{3,4,5\}$. List the elements of $A \cap B$.

Answer: $\{3, 4\}$

The intersection collects exactly the elements belonging to both sets. For comparison, $A \cup B = \{1,2,3,4,5\}$ and $A \setminus B = \{1,2\}$.

Let $A = \{1,2,3\}$. Which statement is false?

  • $\varnothing \subseteq A$
  • $\{1,2\} \subseteq A$
  • $2 \in A$
  • $\{2\} \in A$

Answer: $\{2\} \in A$

The elements of $A$ are the numbers $1$, $2$, $3$ — not sets. So $\{2\} \subseteq A$ is true, but $\{2\} \in A$ is false: the one-element set $\{2\}$ is not itself one of the three elements.

$\varnothing \subseteq A$ holds because "every element of $\varnothing$ lies in $A$" is vacuously true — there are no elements to check.

"If it is raining then the pavement is wet." Given that the pavement is wet, what may you conclude?

  • It is raining.
  • Nothing — the pavement could be wet for another reason.
  • It is not raining.
  • It rained earlier.

Answer: nothing

Concluding "it is raining" uses the converse, which was never claimed. What you may conclude from a dry pavement is that it is not raining — the contrapositive, which is equivalent to the original.

This error has a name, affirming the consequent, and in mathematics it usually appears as a chain of steps run in the wrong direction.

Consider two statements about real numbers:
(i) for every $x$ there exists $y$ with $y > x$;
(ii) there exists $y$ such that for every $x$, $y > x$.

  • Both are true.
  • Both are false.
  • (i) is true and (ii) is false.
  • (i) is false and (ii) is true.

Answer: (i) is true and (ii) is false

For (i), given any $x$ take $y = x + 1$ — the choice of $y$ is allowed to depend on $x$. For (ii), the same $y$ must beat every $x$ at once, including $x = y$, which would need $y > y$. So (ii) fails.

The order of the quantifiers is the entire difference between the two sentences.

To prove "$P$ if and only if $Q$", what must you do?

  • Prove $P \Rightarrow Q$ and prove $Q \Rightarrow P$.
  • Prove $P \Rightarrow Q$ only.
  • Prove the contrapositive of $P \Rightarrow Q$ only.
  • Find one example where $P$ and $Q$ are both true.

Answer: prove both directions

$P \iff Q$ asserts two implications, and each needs its own argument. Option 3 proves only one direction, since the contrapositive is equivalent to $P \Rightarrow Q$ and says nothing about the converse. An example proves nothing at all about a general claim.

Someone claims $\dfrac{1}{a+b} = \dfrac1a + \dfrac1b$ for all non-zero $a, b$. Give a value of $a$ that, with $b = a$, refutes it.

Answer: any non-zero value works — for example $a = 1$

With $a = b = 1$: the left side is $\frac{1}{2}$ and the right side is $2$. Refuted.

In fact taking $b = a$ makes the left side $\frac{1}{2a}$ and the right side $\frac{2}{a}$; these are equal only if $\frac{1}{2a} = \frac2a$, which never happens. So every choice is a counterexample — the claimed rule is not merely usually false, it is always false along this line.

Mixed review: Part I

Eight problems pulled back across every chapter of Part I — nothing new, just recall.

Without a calculator: what is $(-3) \times (-4) \times (-1)$?

Answer: $-12$

$(-3)\times(-4) = 12$ (two negatives make a positive), then $12 \times (-1) = -12$. An odd number of negative factors leaves the product negative — the rule of signs from Chapter 1.

Add the fractions: $\dfrac23 + \dfrac56$.

Answer: $\dfrac32$

Rewrite both over the common denominator $6$: $\dfrac46 + \dfrac56 = \dfrac96 = \dfrac32$ — the same rewriting rule from Chapter 1.

Solve the system $x + y = 7$, $\; x - y = 1$. What is $x$?

Answer: $x = 4$

Adding the two equations eliminates $y$: $2x = 8$, so $x = 4$ (and then $y = 3$) — the elimination move from Chapter 2.

Two numbers have a sum of $20$ and a difference of $4$. What is the larger number?

Answer: $12$

With $x + y = 20$ and $x - y = 4$, adding gives $2x = 24$, so $x = 12$ (and $y = 8$) — the same setup as Chapter 2.

Which interval is the solution set of $|x - 3| < 2$?

  • $(1, 5)$
  • $(-2, 2)$
  • $(1, 3)$
  • $(-5, -1)$

Answer: $(1, 5)$

$|x-3| < 2$ means $-2 < x - 3 < 2$; adding $3$ throughout gives $1 < x < 5$ — the same unfolding from Chapter 3.

Simplify $2^{-3} \cdot 2^{5}$.

Answer: $4$

$2^{-3}\cdot 2^5 = 2^{-3+5} = 2^2 = 4$, by the first law of exponents from Chapter 3.

How many real solutions does $x^2 + 4x + 5 = 0$ have?

  • None
  • One
  • Two
  • Infinitely many

Answer: none

The discriminant is $4^2 - 4(1)(5) = 16 - 20 = -4 < 0$, so there is no real solution — the discriminant test from Chapter 4.

Solve $x^2 - 5x + 6 = 0$. What is the larger root?

Answer: $3$

$x^2 - 5x + 6 = (x-2)(x-3)$, so the roots are $2$ and $3$ — the zero-product move from Chapter 4.

Recap

  • $P \Rightarrow Q$, its converse $Q \Rightarrow P$, and its contrapositive $\text{not }Q \Rightarrow \text{not }P$: the contrapositive is equivalent, the converse is a different statement.
  • An implication with a false hypothesis is true, vacuously.
  • "For all" is refuted by one counterexample; "there exists" is proved by one example.
  • Negating "for all $x$, $P$" gives "there exists $x$ with not $P$" — and the order of quantifiers changes the meaning.
  • Sets: $\in$, $\subseteq$, $\cup$, $\cap$, $\setminus$, $\varnothing$; and $A = B$ is proved in two halves.
  • Notation should carry meaning: name things once, keep different objects on different letters, and never write $=$ where you mean $\Rightarrow$.
