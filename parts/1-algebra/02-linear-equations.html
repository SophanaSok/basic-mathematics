Part I — Algebra · Chapter 2

Linear Equations

An equation is a question: for which values of the unknowns is this true? Solving it means replacing the question with an easier one that has the same answers.

By the end of this chapter you can solve a linear equation in one unknown and justify each step, solve systems in two and three unknowns by elimination, recognise from the arithmetic alone whether a system has one solution, none, or infinitely many, and turn a word problem into equations.
Before you start

You should be comfortable with the rules of addition and multiplication and with division as multiplication by an inverse (Chapter 1). Every move in this chapter is one of those rules applied to both sides at once.

2.1 One unknown

A linear equation in the unknown $x$ is one that can be written $ax + b = 0$ with $a$ and $b$ numbers. "Linear" means: $x$ appears to the first power only — no $x^2$, no $\frac1x$, no $\sqrt{x}$.

A solution is a number which, substituted for $x$, makes the statement true. To solve is to find all of them. Only two moves are ever needed, and both are safe because both can be undone:

The two legal moves
  1. Add the same number to both sides. If $u = v$ then $u + c = v + c$; and adding $-c$ brings you back. Nothing is gained or lost.
  2. Multiply both sides by the same non-zero number. If $u = v$ then $cu = cv$; multiplying by $c^{-1}$ brings you back — which is exactly why $c \neq 0$ is required.
Watch out

Multiplying both sides by $0$ turns any equation into $0 = 0$, which is true for every $x$ and tells you nothing. The step cannot be undone, so it loses information. This is the same prohibition as in Chapter 1: $0$ has no inverse.

Wrong turn. Dividing by a letter that might be zero

Solve $3x = 5x$.

  1. The tempting move. Both sides have a factor of $x$, so divide by it: $3 = 5$.
  2. That is false, so the equation appears to have no solution at all.
  3. The check. Try $x = 0$ in the original: the left side is $0$, the right side is $0$. It solves the equation. So "no solution" is wrong — and notice the damage was done by a step that looked like tidying up.
  4. The repair. Collect on one side instead of dividing: $3x - 5x = 0$, so $-2x = 0$, and dividing by $-2$ — a number known not to be zero — gives $x = 0$. That is the whole solution set. $\blacksquare$

Dividing by $x$ silently assumes $x \neq 0$, and so throws away the very solution that was there. The two permitted moves are safe precisely because they can be undone; this one cannot. When a factor you want to cancel contains an unknown, move everything to one side rather than dividing.

Example 1. Solving with the reason for every step

Solve $5x - 3 = 2x + 9$.

  1. Add $-2x$ to both sides: $3x - 3 = 9$. Move 1, collecting the unknown on one side.
  2. Add $3$ to both sides: $3x = 12$.
  3. Multiply both sides by $\frac13$ — legal, since $\frac13 \neq 0$: $x = 4$.
  4. Check by substituting into the original equation: $5(4) - 3 = 17$ and $2(4) + 9 = 17$. ✓

The check is not optional politeness. It is the only step that catches an arithmetic slip, and it costs ten seconds.

Not every linear equation has exactly one solution. Consider what happens when the unknown disappears:

EquationReduces toSolutions
$3x + 1 = 7$$x = 2$exactly one
$2x + 5 = 2x + 5$$0 = 0$every number — an identity
$2x + 5 = 2x + 1$$5 = 1$none — a contradiction

Those three outcomes — one, all, none — are the only possibilities, and the same trichotomy will reappear for systems in a moment. When the unknown cancels out, read the surviving numerical statement: if it is true, every number is a solution; if it is false, none is.

2.2 Equations in two unknowns

One equation in two unknowns, such as $x + y = 5$, has infinitely many solutions — a solution is now a pair $(x, y)$, and pairs like $(0,5)$, $(2,3)$, $(-1,6)$ all qualify. To pin the pair down you generally need two equations at once:

$$\begin{aligned} a_1x + b_1y &= c_1 \\ a_2x + b_2y &= c_2 \end{aligned}$$

A solution of the system is a pair satisfying both equations. The method is elimination: combine the two equations so that one unknown vanishes, leaving one equation in one unknown — which we already know how to solve.

The third legal move

Replacing one equation of a system by (that equation) $+$ $c \times$ (another equation) does not change the solution set. Any pair satisfying both originals satisfies the combination; and the move is undone by subtracting $c$ times the same equation.

Example 2. Elimination

Solve $\;\begin{aligned}[t] 2x + 3y &= 12\\ x - y &= 1\end{aligned}$

  1. Multiply the second equation by $3$: $3x - 3y = 3$. The $y$-coefficients are now $+3$ and $-3$.
  2. Add the two equations. The $y$ terms cancel: $(2x + 3y) + (3x - 3y) = 12 + 3$, that is $5x = 15$.
  3. So $x = 3$.
  4. Back-substitute into either original equation — the simpler one, $x - y = 1$: $3 - y = 1$, so $y = 2$.
  5. Check in both originals: $2(3) + 3(2) = 12$ ✓ and $3 - 2 = 1$ ✓. The solution is $(x,y) = (3,2)$. $\blacksquare$

When does elimination fail to produce an answer? Exactly when the unknown cancels out completely. Multiply the first equation by $a_2$, the second by $a_1$, and subtract; the $x$ terms vanish and you are left with

$$(a_1b_2 - a_2b_1)\,y = a_1c_2 - a_2c_1.$$

Everything now depends on the single number $a_1b_2 - a_2b_1$.

The trichotomy for a 2 × 2 system
  • If $a_1b_2 - a_2b_1 \neq 0$: divide, and there is exactly one solution.
  • If $a_1b_2 - a_2b_1 = 0$ and the right-hand side is also $0$: the two equations say the same thing, and there are infinitely many solutions.
  • If $a_1b_2 - a_2b_1 = 0$ but the right-hand side is not: you have derived $0 = (\text{something non-zero})$, so there is no solution.

That number $a_1b_2 - a_2b_1$ has a name — the determinant of the system — and a geometric meaning we will meet in Chapter 16. Geometrically, each equation describes a line (Chapter 10); the three cases are lines crossing once, the same line twice, and parallel lines.

2.3 Equations in three unknowns

Nothing new happens — only bookkeeping. With three unknowns you use one equation to eliminate one unknown from the others, reducing to a $2\times2$ system, then solve that and work backwards. Being systematic is the whole skill.

Example 3. A 3 × 3 system

Solve $\;\begin{aligned}[t] x + y + z &= 6 \\ 2x - y + z &= 3 \\ x + 2y - z &= 2 \end{aligned}$

  1. Eliminate $x$ from equations 2 and 3 using equation 1. Equation 2 minus $2\times$ equation 1: $(2x - y + z) - 2(x + y + z) = 3 - 12$, i.e. $-3y - z = -9$. Equation 3 minus equation 1: $y - 2z = -4$.
  2. Now a $2\times2$ system in $y, z$: $\begin{aligned}[t] -3y - z &= -9 \\ y - 2z &= -4 \end{aligned}$
  3. Eliminate $y$: add $3\times$ the second equation to the first: $(-3y - z) + 3(y - 2z) = -9 + (-12)$, giving $-7z = -21$, so $z = 3$.
  4. Back-substitute into $y - 2z = -4$: $y - 6 = -4$, so $y = 2$.
  5. Back-substitute into equation 1: $x + 2 + 3 = 6$, so $x = 1$.
  6. Check all three originals: $1+2+3 = 6$ ✓, $2 - 2 + 3 = 3$ ✓, $1 + 4 - 3 = 2$ ✓. So $(x,y,z) = (1,2,3)$. $\blacksquare$
Keeping it tidy

Write each new system on its own line, aligned in columns, and label which equation you combined with which. Most errors in this chapter are transcription errors, not misunderstandings — and an aligned layout makes them visible. The same trichotomy holds: if every unknown cancels and you are left with a true statement, there are infinitely many solutions; with a false one, none.

2.4 Turning words into equations

The mathematics above is mechanical. The genuinely difficult step is the translation, and it has a reliable procedure:

  1. Name the unknowns with letters, and write down what each letter means, including its units. Vagueness here is fatal later.
  2. Find one equation per independent fact in the problem. A system in three unknowns needs three facts.
  3. Solve, then interpret: convert the numbers back into a sentence answering the question actually asked.

Example 4. From sentences to symbols

A cinema sells adult tickets at £9 and child tickets at £5. One showing sold 120 tickets and took £868. How many of each were sold?

  1. Name: let $a$ = number of adult tickets, $c$ = number of child tickets.
  2. Fact one, the count: $a + c = 120$.
  3. Fact two, the money (in pounds): $9a + 5c = 868$.
  4. Eliminate $c$: multiply the first equation by $5$ and subtract from the second: $(9a + 5c) - 5(a + c) = 868 - 600$, so $4a = 268$ and $a = 67$.
  5. Then $c = 120 - 67 = 53$.
  6. Check: $67 + 53 = 120$ ✓, and $9(67) + 5(53) = 603 + 265 = 868$ ✓. Answer: 67 adult and 53 child tickets. $\blacksquare$

Practice

For systems, give the answer as the requested single number — that keeps the checking unambiguous. Always verify your full solution in the original equations.

Solve $7x - 5 = 3x + 11$ for $x$.

Answer: $x = 4$

Add $-3x$: $4x - 5 = 11$. Add $5$: $4x = 16$. Multiply by $\frac14$: $x = 4$. Check: $7(4) - 5 = 23$ and $3(4) + 11 = 23$ ✓.

Solve $3(x + 4) = 5(x - 2)$ for $x$.

Answer: $x = 11$

Distributivity gives $3x + 12 = 5x - 10$. Add $-3x$ to both sides: $12 = 2x - 10$. Add $10$: $22 = 2x$. Multiply by $\frac12$: $x = 11$.

Check in the original: $3(11 + 4) = 45$ and $5(11 - 2) = 45$ ✓.

How many solutions does $4x + 7 = 4x - 2$ have?

  • Exactly one.
  • Infinitely many — every number is a solution.
  • None.
  • Exactly two.

Answer: none

Adding $-4x$ to both sides leaves $7 = -2$, which is false. No value of $x$ can make the original true, so the solution set is empty. Compare $4x + 7 = 4x + 7$, which reduces to $7 = 7$ — true for every $x$.

Solve $\;\begin{aligned}[t] 3x + 2y &= 16 \\ x - y &= 2 \end{aligned}$ and give the value of $x$.

Answer: $x = 4$

Multiply the second equation by $2$: $2x - 2y = 4$. The $y$-coefficients are now $+2$ and $-2$, so adding the two equations eliminates $y$: $$(3x + 2y) + (2x - 2y) = 16 + 4 \quad\Longrightarrow\quad 5x = 20,$$ so $x = 4$. Back-substituting into $x - y = 2$ gives $y = 2$.

Check in both originals: $3(4) + 2(2) = 16$ ✓ and $4 - 2 = 2$ ✓.

For which value of $k$ does the system $\;\begin{aligned}[t] 2x + 3y &= 7 \\ 4x + ky &= 1 \end{aligned}$ fail to have exactly one solution?

Answer: $k = 6$

Elimination leaves the coefficient $a_1b_2 - a_2b_1 = 2k - 12$. Exactly one solution requires this to be non-zero, so the exceptional value is $2k - 12 = 0$, i.e. $k = 6$.

With $k = 6$ the second equation reads $4x + 6y = 1$, which is $2\times$ the left-hand side of the first but with right-hand side $1$ instead of $14$ — a contradiction, so in this case there is no solution rather than infinitely many.

Solve $\;\begin{aligned}[t] x + y + z &= 4 \\ 2x - y + 3z &= 14 \\ x + 2y - z &= -3 \end{aligned}$ and give the value of $z$.

Answer: $z = 3$

Eliminate $x$ using equation 1. Equation 2 minus $2\times$ equation 1: $$(2x - y + 3z) - 2(x + y + z) = 14 - 8 \quad\Longrightarrow\quad -3y + z = 6.$$ Equation 3 minus equation 1: $$(x + 2y - z) - (x + y + z) = -3 - 4 \quad\Longrightarrow\quad y - 2z = -7.$$

From the second, $y = 2z - 7$. Substitute into the first: $-3(2z - 7) + z = 6$, so $-5z + 21 = 6$, giving $z = 3$. Then $y = -1$, and equation 1 gives $x = 4 - (-1) - 3 = 2$.

Check all three: $2 - 1 + 3 = 4$ ✓, $4 + 1 + 9 = 14$ ✓, $2 - 2 - 3 = -3$ ✓.

The sum of two numbers is $20$ and their difference is $8$. What is the larger number?

Answer: $14$

Let $x$ be the larger and $y$ the smaller. Then $x + y = 20$ and $x - y = 8$. Adding the two equations eliminates $y$: $2x = 28$, so $x = 14$, and then $y = 6$. Check: $14 + 6 = 20$ ✓, $14 - 6 = 8$ ✓.

A stall sells coffee at £3 and tea at £2. It sold $50$ drinks and took £135. How many coffees were sold?

Answer: $35$ coffees

Let $c$ = coffees, $t$ = teas. Then $c + t = 50$ and $3c + 2t = 135$. Subtract $2\times$ the first from the second: $(3c + 2t) - 2(c + t) = 135 - 100$, so $c = 35$, and $t = 15$. Check: $35 + 15 = 50$ ✓ and $3(35) + 2(15) = 105 + 30 = 135$ ✓.

Which of these operations on an equation can change its set of solutions?

  • Adding $-7$ to both sides.
  • Multiplying both sides by $x - 1$.
  • Multiplying both sides by $\frac{1}{2}$.
  • Swapping the two sides.

Answer: multiplying both sides by $x - 1$

The multiplier $x - 1$ is $0$ when $x = 1$, so the step can manufacture $x = 1$ as a spurious extra solution — and it cannot be undone, because you cannot divide by something that might be zero. The other three moves are reversible and therefore safe. This is why every solution must be checked in the original equation.

Recap

  • Solving = replacing an equation by a simpler one with the same solutions. The safe moves are: add anything to both sides; multiply both sides by something non-zero; add a multiple of one equation of a system to another.
  • Elimination reduces a system in $n$ unknowns to one in $n-1$ unknowns. Repeat, then back-substitute.
  • Every linear system has exactly one solution, infinitely many, or none. For a $2\times2$ system the number $a_1b_2 - a_2b_1$ decides which.
  • In word problems: name the unknowns with units, extract one equation per fact, solve, then answer the question in words.
  • Check in the original equations, always.
